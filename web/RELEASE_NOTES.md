# Release notes

## 0.1.2 — 2026-11-05

- Кнопка «Подтвердить» на экране Cloze стала менее яркой.
- Поле ввода на экране Cloze стало шире. Расширяется оно, только когда введённый текст доходит до правого края.
- Плашка «Стрик на сегодня засчитан» больше не висит до конца дня: она скрывается через 15 секунд или через две карточки. После переоткрытия приложения она снова не появляется.
