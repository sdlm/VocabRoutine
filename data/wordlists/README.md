# Частотные списки NGSL Project

Источник слов для карточек: из этих списков берутся леммы и `freqRank`, остальное содержимое карточек генерируется. Веб-приложение эти файлы не читает.

Источник: https://www.newgeneralservicelist.com/word-lists (Creative Commons, бесплатно, в том числе для коммерческого использования). Здесь лежат нормализованные версии файлов `*_stats.csv`. При использовании нужно указывать NGSL Project как источник.

## Формат

Кодировка UTF-8, разделитель запятая, первая строка с заголовком:

| Колонка | Описание |
|---|---|
| `lemma` | слово (лемма) |
| `rank` | ранг по частоте внутри списка, целое число |
| `sfi` | Standard Frequency Index |
| `u` | оценочная частота на миллион слов |

## Особенности

- Rank, SFI и U считаются по корпусу каждого списка, поэтому у одного слова в разных файлах значения различаются. Ранги разных списков между собой не сравнимы.
- `FEL`, `NDL` и `NGSL-Spoken` отсортированы по алфавиту, остальные по `rank`.
- В `TSL` у пяти слов `sfi` и `u` пустые (в источнике `#N/A`): `correctly`, `birthday`, `textbook`, `semester`, `ma'am`.
- В `NGSL-Spoken` пропущена строка `TRUE` (слово `true`, испорченное Excel, без данных), поэтому ранги идут до 721.
- В `NGSL` строки `TRUE` и `FALSE` (испорчены Excel) исправлены на `true` и `false`.
- В `FEL` шесть записей объединяют полную и короткую форму через ` / `: `abdominal / abs`, `carbohydrate / carbs`, `cardiovascular / cardio`, `deltoid / delts`, `gluteus / glutes`, `repetition / reps`.
- `NGSL` начинается со служебных слов (`the`, `be`, `and`, `of`…), для карточек они не подходят.
